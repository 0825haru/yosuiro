# 金沢用水デジタルガイド

用水沿いの看板のQRコードを読み取ると、その場所の歴史・写真・地図を見られるWebアプリです。
スタンプ機能で、訪れた用水を一覧で確認できます。

## 目的
- 案内板を増やさずに、用水の歴史や景観の情報を届ける
- インストール不要のWebアプリで、更新を即時に反映する
- 地域住民・学生・観光協会が協力して運用できる仕組みにする

## ディレクトリ構成

```
kanazawa-yosui/
  README.md
  docs/        仕様書・運用手順
  data/        元データ(CSV)
  scripts/     変換スクリプト(convert.py)
  api/         出力JSON(自動生成。手で編集しない)
  frontend/    HTML / CSS / JS
  sample/      サンプルJSON
  archive/     使わないが残すもの
```

| フォルダ | 役割 | 主に触る人 |
|---|---|---|
| `data/` | 元データ(`spots.csv`) | データ整理担当 |
| `scripts/` | CSV → JSON の変換スクリプト | バックエンド |
| `api/` | 公開用JSON。**手で編集しない** | (自動生成) |
| `frontend/` | 画面 | フロント担当 |
| `docs/` | API仕様書など | 全員 |
| `sample/` | サンプルJSON | サンプル担当 |
| `archive/` | 使わないが残すもの。**増やさない** | 全員 |

## データの更新手順
1. `data/spots.csv` を編集する(`published` が `1` の行だけ公開される)
2. リポジトリのルートで `python scripts/convert.py` を実行する
3. エラー・警告が出ていないか確認する
4. `api/` の変更を含めて commit → push
5. 公開サイトで反映を確認する

## チームのルール
- `api/` は手で編集しない(スクリプトが生成する)
- 作業前に pull、作業後に push する
- 仕様(項目名など)を変えるときは、先にフロント担当に相談する
- 使わないファイルは削除せず `archive/` へ
