# API仕様書

## 命名ルール

### スポットID
- 形式: `kw-` + 3桁連番(例: kw-001)
- 一度発行したIDは変更・再利用しない

### QRコードのURL
- 形式: https://example.jp/s/{spot_id}
- 例: https://example.jp/s/kw-001

### 言語コード
- ja(基準言語)、en
- 未翻訳の場合は ja にフォールバック（日本語版の文章を表示）する

## 共通ルール
- 文字コード: UTF-8、JSON
- 日時: ISO 8601(+09:00 付き)
- 項目名: スネークケース(例: canal_name、updated_at)
- 値がない項目は null(項目自体は省略しない)

---

## GET /api/spots

スポット一覧を返す(公開済みのみ)。

### クエリパラメータ
| 名前 | 必須 | 説明 |
|---|---|---|
| lang | 任意 | 言語。省略時 ja |

### レスポンス 200
```json
{
  "spots": [
    {
      "id": "kw-001",
      "name": "大野庄用水(長町武家屋敷跡)",
      "canalName": "大野庄用水",
      "lat": 36.5558,
      "lng": 136.6515,
      "thumbnailUrl": null
    }
  ],
  "updatedAt": "2026-10-14T10:00:00+09:00"
}
```

---

## GET /api/spots/{id}

スポット詳細を返す。

### レスポンス 200
```json
{
  "id": "kw-001",
  "lang": "ja",
  "isFallback": false,
  "name": "大野庄用水(長町武家屋敷跡)",
  "canalName": "大野庄用水",
  "description": "説明文",
  "lat": 36.5558,
  "lng": 136.6515,
  "media": [],
  "updatedAt": "2026-10-14T10:00:00+09:00"
}
```

### エラー
| ステータス | 条件 |
|---|---|
| 404 | IDが存在しない、または非公開 |
